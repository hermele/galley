# Contributing to galley

Thank you for your interest in galley.

- **Bug reports and suggestions are welcome as GitHub issues.** Please include your operating
  system, Python version, the agent you use (Codex or Claude Code), and, where it matters, a
  small LaTeX example that you are happy to share publicly. galley is maintained on a
  best-effort basis, so there is no guarantee of a reply or a fix.
- **Pull requests are not accepted for now.** If you have a change in mind, please describe it
  in an issue instead. You are free to modify galley in your own copy or fork under its license
  (see `LICENSE` and `NOTICE`, including the attribution term).
- **Security problems:** please do not open a public issue; see `SECURITY.md`.
