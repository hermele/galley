# Security

galley is a local web server that opens documents written by other people and runs AI agents
and LaTeX on them, so security reports are taken seriously.

To report a vulnerability, please use GitHub's private reporting: the **Security** tab of this
repository, then **Report a vulnerability**. Please do not open a public issue for it.

What galley is designed to guarantee is described under "Security" in `README.md`. Reports are
handled on a best-effort basis; fixes are released as new versions on the repository's Releases page.
